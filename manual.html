1. The daily routine

Two ways to run it. Shared mode (section 10) saves everything to a private Google Sheet, so you and a teammate just sign in and the data is already there. Single-user mode (below) keeps nothing anywhere except the CSV files you save. The app picks the mode from config.js.

In single-user mode, FINANCE HUB stores nothing on a server or on your computer. Your data exists only in the browser tab while it is open, so a CSV file is how you keep it.

1
Import
Open the site and click Import CSV. Choose yesterday’s file. Pick Merge.
2
Work
Add sales, expenses, income and payments. Everything recalculates instantly.
3
Export
Before you leave, click Export all (CSV). Keep the file somewhere safe.

The yellow badge tells you whether you have work that is not yet in a file. The browser also warns you if you try to close the tab with unexported changes. A refresh keeps your data; closing the tab clears it.

2. First-time setup (Settings)

The app starts completely empty. Nothing is pre-filled, so add your own lists first under Settings. The dropdowns everywhere else are built from them.

ListWhat to add
Team & assigneesYourself first, then anyone who makes sales. Optional role and a monthly sales target.
Sales platformsWhere sales come from (for example Telegram or Facebook).
Sales transaction categoriesYour own types, such as subscriptions, tips or referrals.
Payment methodsHow people pay you or how you pay.
Verification statusesFor example Confirmed, Verifying, Duplicate, Not Found. Tick “Counts as confirmed revenue” on the ones that are real money. Until one is ticked, all sales show as unverified.
Expense, income, debt types, recurrenceCategories for budgeting. For recurrence, enter how many months and/or days it repeats (Monthly = 1 month, Weekly = 7 days).

You can edit or deactivate any option later. Old records keep working because they point to the option’s ID, not its name. Customers have their own page in the sidebar, or you can type a new name directly in the sales form.

3. Recording sales

Open Sales Tracker and click + Add sale. Fields: date, Sales from (the team member), Sender (the customer), transaction ID, amount, platform, transaction type, payment method, confirmation status and notes.

  • Verified vs unverified: only sales whose status is marked “counts as confirmed” are confirmed revenue. Everything else is shown as unverified.
  • Duplicates: if you reuse a transaction ID the app asks before saving, and the table shows a “Check duplicate” tag. You decide whether it is a real duplicate.
  • Search the table, and use the From / To dates at the top to filter every page.
  • Delete hides a record from totals but keeps it in your export, so deletions carry over when you import on another day.

4. Reports and analytics

  • Overview: totals, circular progress, donut, line and bar charts. Click a donut segment to see the records behind it.
  • Sales Analytics: employee ranking, contribution, platform trends and target achievement.
  • Reports: choose Monthly or Weekly and a period. You get totals by employee, platform and type, top performers, confirmed vs unverified, and growth against the previous period. Use Export CSV or Print on it.

5. Budget, income, expenses, debts and goals

  • Budget Manager: pick a month, add a budget per category. You see planned, actual, remaining, percent used, last month, and a forecast (a projection, not a result). Warning levels are set in Settings (default 75% and 90%).
  • Expenses and Income: add records; totals feed the overview and budgets.
  • Recurring Payments: set the next due date and recurrence. Mark paid records one expense and moves the due date forward. It never creates duplicates by itself.
  • Debts: enter the balance, interest rate and minimum payment. Record payment splits interest from principal and updates the estimated payoff.
  • Savings Goals: set a target and use Add for contributions.

6. Import and export in detail

Export

  • Export all (CSV) creates one dated file, like finance-hub-2026-11-10.csv, with everything: records, team, customers, categories and settings. This is your backup.
  • Export selected date range (Settings) exports only the sales, expenses, income and debt payments inside the From/To dates, plus all lists and other records. Handy for small daily files.
  • The Export CSV button on each page makes a simple, Excel-friendly file of just that table.

Import

  • Merge (recommended) adds new records and updates ones where the file has a newer edit. Records already up to date are left alone, so importing the same file twice is safe.
  • Replace everything wipes the tab first. Use it for a clean start from one file.
  • A preview shows how many records are new or updated before anything changes.
Tips. Don’t rename the first two columns (table, id) or edit IDs. You can open the file in Excel to look, but save it as CSV UTF-8 (comma delimited) if you edit it. Always keep the latest file; older ones can be kept as history.

7. Publishing on GitHub Pages (free)

You upload index.html (the app), manual.html (this page) and config.js (empty unless you use shared mode). The charts load from a public library, so visitors need an internet connection.

1
Account
Sign in at github.com (create a free account if needed).
2
New repository
Click + → New repository. Name it finance-hub, set it to Public, and create it.
3
Upload
Click Add file → Upload files, drop index.html, manual.html, config.js and README.md, then Commit changes.
4
Turn on Pages
Settings → Pages. Under “Build and deployment” choose Deploy from a branch, branch main, folder / (root), then Save.
5
Open it
After a minute or two your site is at https://YOUR-USERNAME.github.io/finance-hub/. The link appears at the top of the Pages screen.

Updating later: open the file in the repo, use the pencil (edit) or Add file → Upload files to replace it, and commit. The site refreshes by itself in a minute.

Bookmark it. The first load of the day: open the bookmark, import your CSV, and go.

8. Privacy and safety

  • The repository is public, but your numbers never go into it. They stay in your own browser tab and in the CSV files you save yourself.
  • Never upload a real export CSV to GitHub. Keep CSVs in your own storage (a folder, cloud drive or USB stick).
  • On a shared computer, export, then close the tab. Closing the tab clears everything.
  • Do not enter passwords or login codes into the app. It has no need for them.
  • Back up regularly: files can be lost. A second copy in another place is wise.

9. Troubleshooting

ProblemWhat to do
Charts are empty or missingYou may be offline (the chart library loads from the internet) or have no records in the selected dates. Click Clear dates.
Everything shows as unverifiedIn Settings → Verification statuses, tick “Counts as confirmed revenue” on the right statuses.
“Not a FINANCE HUB export”Only files made by Export all (CSV) can be imported. Don’t import the per-page CSVs.
Names show blank after importImport the full export; the team, customers and category lists are inside it.
I closed the tab by mistakeData not exported is gone. Import your latest CSV. Export more often.
Download didn’t startAllow downloads for the site in your browser, then try again.
My site shows a 404Check that the file is named exactly index.html and that Pages is set to branch main, folder / (root). Wait two minutes.

10. Shared mode: you and a teammate

With shared mode on, nobody imports CSVs. Everyone signs in with Google and the same data appears for both of you.

1
Open the site
Click Sign in with Google (top bar). Pick your Google account.
2
Data loads
The badge shows Syncing… then Synced. Everything is there.
3
Work
Add and edit as usual. Changes save in a few seconds and your teammate’s changes appear within about 30 seconds.
  • Only listed accounts get in. Anyone else who signs in is refused and sees no data.
  • Sessions last about an hour. If the badge asks you to sign in again, click the button. Nothing you typed is lost.
  • Same record, two people. Nothing is overwritten. The second person is asked in Settings → Shared data to choose Keep mine or Use the other version.
  • Deleting hides a record from totals for everyone but keeps it in the Sheet and in exports.
  • CSV still works as an extra backup, and importing a CSV merges into the shared data. “Replace everything” is turned off in shared mode to protect the shared data.
  • Backups: Settings → Back up the Sheet creates a dated copy in the owner’s Google Drive.
The one-time setup (Google sign-in, the Sheet and the connection) is described in SYNC-SETUP.md. It takes about 20 minutes and is done by the owner only.
